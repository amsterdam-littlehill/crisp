# Shared Skills

> Cross-skill universal conventions belong here.
> When a project installs multiple skills, shared rules and toolchain
> configurations live here.

## Usage

Reference from an individual skill's SKILL.md:

```markdown
## Always Read
1. `rules/project-rules.md`
2. ../shared/toolchain-rules.md   <- shared rules reference
                                      (omit for single-skill projects)
```
